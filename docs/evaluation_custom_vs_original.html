Evaluation: custom Node2Vec và Node2Vec gốc

Quy trình chạy qua main.py và test.py, sử dụng cùng Karate Club graph và cùng bài toán phân loại node.

Tài liệu tập trung vào cách so sánh công bằng, dữ liệu đầu vào/đầu ra, metric và cách diễn giải kết quả.

Kết luận của evaluation: embedding custom và embedding từ package node2vec đều được dùng làm feature cho cùng một Logistic Regression classifier trên cùng các train/test split.

1. Mục tiêu đánh giá

Node2Vec là phương pháp học biểu diễn không giám sát: trong lúc học embedding, model không dùng nhãn “Mr. Hi” hay “Officer”. Evaluation dùng nhãn chỉ sau khi embedding đã được tạo để kiểm tra embedding có chứa thông tin hữu ích cho một downstream task hay không.

Evaluation không so sánh trực tiếp từng tọa độ vector. Hai mô hình có thể tạo embedding tương đương nhưng bị xoay, phản chiếu hoặc đổi hệ trục. Thay vào đó, so sánh khả năng phục vụ cùng một nhiệm vụ phân loại.

2. Chuẩn bị trong main.py

2.1. Reproducibility và graph

seed = 42
random.seed(seed)
np.random.seed(seed)

Code dùng seed 42 cho Python, NumPy và PyTorch. Graph là Zachary Karate Club của NetworkX, gồm 34 node và 78 edge. Nhãn câu lạc bộ đã nằm trong thuộc tính node nhưng chưa được dùng khi train embedding.

3. Sinh embedding custom

  
node2vec = Node2Vec(
    G=G, p=p, q=q,
    dimension=embedding_dim,
    walks_per_node=walks_per_node,
    walk_length=walk_length,
    context_size=context_size,
)

custom_embeddings = node2vec.fit(
    num_negative=num_negative,
    batch_size=256,
    epochs=1,
    lr=0.001,
    device=device,
)

  
fit() của custom implementation thực hiện toàn bộ pipeline:

  
    
    
  1. Tiền tính transition probabilities từ p, q.
    2. 
    
  2. Tạo 10 × |V| random walks.
    3. 
    
  3. Tạo positive pairs từ các node trong walk.
    4. 
    
  4. Tạo 5 negative contexts cho mỗi positive pair theo tần suất node0.75.
    5. 
    
  5. Map node label sang integer ID và tạo TensorDataset.
    6. 
    
  6. Train hai bảng embedding bằng Skip-gram, negative-sampling loss và Adam.
    7. 
    
  7. Trả về source_embedding.weight.
    8. 
  

  
Trong kết quả trả về, dòng thứ i tương ứng với node thứ i trong list(G.nodes()).


  
4. Sinh embedding từ package gốc

  
original_node2vec = OriginalNode2Vec(
    graph=G,
    dimensions=embedding_dim,
    walk_length=walk_length,
    num_walks=walks_per_node,
    p=p,
    q=q,
    workers=1,
    quiet=True,
    seed=seed,
)

original_model = original_node2vec.fit(
    window=context_size,
    min_count=1,
    batch_words=256,
    epochs=1,
    seed=seed,
)

original_embeddings = np.asarray([
    original_model.wv.get_vector(str(node))
    for node in G.nodes()
])

  
Package gốc tạo model Skip-gram thông qua stack của package node2vec và gensim. Code lấy vector bằng original_model.wv.get_vector(str(node)), rồi xếp theo đúng thứ tự G.nodes() để hai ma trận có cùng ý nghĩa theo hàng.

Negative sampling cố định num_negative=5Negative sampling do gensim configuration mặc định/implementation đảm nhiệm

    
Output là source embedding tableOutput lấy từ model.wv

    
Mapping dùng node label trực tiếp trong node2idVector được truy vấn bằng chuỗi str(node)

7. Chia train/test công bằng

  
splitter = StratifiedShuffleSplit(
    n_splits=30,
    test_size=0.3,
    random_state=42,
)

  
StratifiedShuffleSplit tạo 30 lần chia ngẫu nhiên; mỗi lần dùng 70% node để train và 30% node để test, đồng thời giữ tỷ lệ hai class gần giống nhau ở hai tập.

  
Đối với mỗi embedding file, code gọi cùng splitter và cùng nhãn y. Vì splitter có random_state=42, hai phương pháp được đánh giá trên cùng các index train/test tương ứng.

  
Mỗi lần lặp: embedding X → X_train/X_test → classifier.fit → classifier.predict → metrics


  
8. Classifier và metrics

  
8.1. Logistic Regression

  
clf = LogisticRegression(
    max_iter=1000,
    random_state=42
)

clf.fit(X_train, y_train)
predictions = clf.predict(X_test)

  
Logistic Regression là linear probe: nó kiểm tra liệu thông tin phân biệt hai club có thể được tách bằng một biên tuyến tính trên embedding hay không. Classifier không được phép thấy test labels trong lúc fit.

  
8.2. Accuracy

  
Accuracy = số dự đoán đúng / tổng số mẫu test

  
Accuracy dễ đọc và phù hợp khi hai class không quá lệch. Giá trị càng gần 1 càng tốt.

  
8.3. F1 score

  
F1 = 2 × Precision × Recall / (Precision + Recall)

  
Code gọi f1_score(y_test, predictions) với thiết lập mặc định của sklearn cho bài toán nhị phân. F1 cân bằng precision và recall, hữu ích khi muốn tránh model chỉ dự đoán tốt một class.

  
8.4. Mean và standard deviation

  
accuracies.append(accuracy_score(y_test, predictions))
f1_scores.append(f1_score(y_test, predictions))

mean = np.mean(scores)
std = np.std(scores)

  
Kết quả cuối là mean ± std trên 30 split:

  • Std thấp: kết quả ổn định hơn khi thay đổi tập train/test.
    • 
    
  • Mean cao nhưng std lớn: có thể phụ thuộc mạnh vào node được chọn vào train set.
